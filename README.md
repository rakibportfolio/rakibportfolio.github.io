# MZ Media Website Clone

This is a complete, pixel-perfect clone of **[mzmedia.digital](https://mzmedia.digital/)**.

## Features Cloned
- **Exact Visual Design & Colors**: Dark theme, glowing gradients, border styling, and brand colors.
- **Typography**: Google Fonts (Inter, Poppins, Syne) matching the original.
- **All Interactive Buttons**: "Let's Talk!", "Get your Product Video", video play triggers, pricing switcher tabs, and consultation booking.
- **All Motions & Animations**:
  - **GSAP Header Ticker**: Rotating "Trusted by", "Served 50+ YC Companies", "Creator of Videos" badges.
  - **Infinite Marquee Tracks**: Continuous smooth-scrolling client brand logos and work showcase cards.
  - **Testimonial Slider & Marquee**: Reviews from ClickUp, Naiive, Reachly, Datoric, etc.
  - **Background Loop Videos**: The exact 4-step process animation videos (Clarity, Understanding, Storytelling, Delivery, Sparks).
  - **Interactive Vimeo Video Popup Modal**: Opens full video with clean close triggers (ESC, close button, backdrop click, or deliberate downward swipe).
  - **Lenis Smooth Scrolling**: Inertial smooth desktop scroll.
  - **FAQ Accordion & Mobile Navigation Menu**: Expand/collapse functionality.

## How to Run

1. Open your terminal in this folder:
   ```bash
   npm start
   ```
   (Or `node server.js`)

2. Open your browser and navigate to:
   **http://localhost:3000**
